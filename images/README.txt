PHOTOS LIVE HERE
  images/            single photos (home page top photo, about photo)
  images/featured/   the featured project slides on the home page
  images/pages/      the top photo on each landing page

You don't need to resize or crop photos to fit - the site does that.
But big phone photos make the site slow, so run the photo tool first:
  python3 tools/prepare_photos.py images/featured

Full guide: HOW-TO-EDIT.md in the main website folder.
